# Code History

Викторина по истории компьютеров и iOS. Учебный проект по книге Kodeco.

## Что умеет приложение

На стартовом экране кнопка запуска. Дальше десять вопросов в случайном порядке, у каждого четыре варианта. В конце показывается счёт.

## Курс

Пример из книги [SwiftUI Apprentice](https://www.kodeco.com/books/swiftui-apprentice). Код примера написал Ben Stone.

## Стек

SwiftUI.

## Запуск

```bash
git clone https://github.com/dpogonia/CodeHistory-Kodeco.git
cd CodeHistory-Kodeco
open CodeHistory.xcodeproj
```

Запустите схему **CodeHistory** на симуляторе iPhone.
