# Code History

A quiz about computer and iOS history. A Kodeco study project.

## What it does

The welcome screen has a start button. The game then asks ten questions in random order, with four answers each. The score is shown at the end.

## Course

Sample from the book [SwiftUI Apprentice](https://www.kodeco.com/books/swiftui-apprentice). The sample was written by Ben Stone.

## Stack

SwiftUI.

## Run

```bash
git clone https://github.com/dpogonia/CodeHistory-KODECO.git
cd CodeHistory-KODECO
open CodeHistory.xcodeproj
```

Run the **CodeHistory** scheme on an iPhone simulator.
